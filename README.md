# Victory Park: демонстрация сайта

Интерактивный дизайн-прототип: главная, семейный подбор, выбор билетов, пакетов и личных безлимитов.

Это демонстрация для обсуждения дизайна. Реальных заказов, оплаты, отправки писем и действительных билетов нет. Цены и правила учебного набора вымышлены. Данные выбора остаются в браузере.

Открывайте `index.html` через статический HTTP-сервер или GitHub Pages. Основные страницы: `index.html`, `attractions.html`, `tickets.html`. Серверная часть и сборка не нужны.

Фотографии и знак: официальный сайт [Victory Park](https://parkvictory.am/ru) и предоставленные материалы бренда. Фотографии не подтверждают текущую доступность или правила аттракционов.

Шрифты Montserrat и Oswald распространяются с уведомлениями и SIL Open Font License в каталогах assets и home-assets. Oswald используется как открытая кириллическая замена заголовочного шрифта для этой демонстрации.
